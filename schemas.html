סכמות המשאבים במערכת (SSR Schemas)

עמוד זה מרונדר בצד השרת באמצעות EJS ומציג את מבנה הנתונים הרשמי עבור כל משאבי ה-API.

משאב

Book

Endpoint: /api/books

Represents a book in the library catalog

שם השדה סוג נתונים חובה/אופציונלי תיאור השדה
id Number אופציונלי Auto-generated unique primary key
title String חובה (Required) Title of the book
author String חובה (Required) Author of the book
category String חובה (Required) Genre category (e.g. Science, Fiction, History)
price Number חובה (Required) Price in USD
rating Number אופציונלי Rating score between 1.0 and 5.0
inStock Boolean אופציונלי Inventory availability status
משאב

Review

Endpoint: /api/reviews Nested: /api/books/:id/reviews

Represents a reader review linked to a specific book

שם השדה סוג נתונים חובה/אופציונלי תיאור השדה
id Number אופציונלי Auto-generated unique review ID
bookId Number חובה (Required) Foreign key referencing associated Book.id
reviewer String חובה (Required) Name of the reviewer
comment String חובה (Required) Review commentary text
rating Number חובה (Required) Score integer from 1 to 5
date String אופציונלי Publication date in YYYY-MM-DD format
